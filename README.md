# HR Analysis Dashboard

## Overview
This project is an interactive HR Analysis Dashboard developed using Power BI to analyze employee workforce data and generate meaningful business insights.

## Objectives
- Analyze employee headcount trends
- Understand gender distribution
- Compare employee distribution across countries and business units
- Track workforce demographics
- Create an interactive reporting experience

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX
- Excel

## Features
- KPI Cards for Employee Metrics
- Employee Headcount Trend Analysis
- Gender Distribution Analysis
- Age Group Analysis
- Country-wise Employee Distribution
- Business Unit Analysis
- Interactive Slicers and Filters
- Search Functionality inside Slicers
- Bookmark Navigation
- Cross-filtering Visuals

## DAX Concepts Used
- COUNT
- CALCULATE
- DIVIDE
- Percentage Measures
- KPI Calculations
- Dynamic Metrics

## Power BI Concepts Learned
- Data Cleaning using Power Query
- Data Modeling and Relationships
- DAX Measure Creation
- Dashboard Design
- Interactive Visualizations
- Bookmark Implementation
- Search Box in Slicers
- Report Navigation

## Dashboard Insights
- Total Employees: 999
- Female Employees: 515 (51.55%)
- Male Employees: 484 (48.45%)
- Workforce analyzed across multiple countries and business units
